Open-source developer tool

Heartbeat

Visualize what your AI coding agents are doing. A local dashboard that turns Codex and Claude Code session activity into signals you can follow.

View on GitHub ↗Installation instructions ↗

Why I built it

Coming from data science, I wanted a dashboard for understanding what happens when AI agents work. An agent can reason, call tools, produce output, or hand work to subagents — and it can be difficult to see what's going on. I took inspiration from an ECG: give each agent its own heartbeat.

How it works

Heartbeat reads session logs already stored locally by OpenAI Codex and Claude Code. It presents agent activity over time, recent events, and cumulative token usage. No changes to your coding agents are required, and session data stays on your machine.

  • See the signal of each agent and its subagents.
  • Follow thinking, tool calls, assistant output, completion and waiting states.
  • Browse recent events and token usage over time.
  • Switch between sessions and time windows.

Try it

Install with Python 3.10+ and pipx install 'git+https://github.com/AhmedOmarO/heartbeat-monitor.git', then run heartbeat.
